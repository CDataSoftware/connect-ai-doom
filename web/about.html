A FIRST FOR MCP

The Model Context Protocol (MCP) is how AI models reach tools and data. As far as we know, this is the first time it has been wired into Doom:

MCP data, played in DoomThe level, its doors and its monsters all come from records Claude read through the Connect AI MCP server.
Doom as an MCP serverWhen Claude plays, Doom itself is an MCP server, with tools to look around, walk and attack.

WHAT YOU'RE SEEING

Rooms
Each room is an app: a Salesforce office, a Zendesk ops center, a Stripe treasury. It's styled after the app, with its own monsters.
Monsters
Each monster is a record from that app: a deal, a ticket, an invoice. Aim at one to read it. The biggest monsters are the urgent records.
Keycards
Your permissions, as Connect AI reports them: blue for an app you can only read, yellow for read and write.
The red door
Data that Connect AI blocked, like a lookup by Social Security number. There is no red key.
The side panel
The score for each room, and every kill as it happens, with the record behind it.

HOW IT WORKS

  1. Claude reads your data.Claude gets one MCP server, Connect AI, limited to its read-only tools. Claude finds the three apps that answer the question and writes one query for each.
  2. The level is built from the answer.Rows become monsters, and Connect AI's permissions become the door colors. A request Connect AI refused becomes the vault behind the red door.
  3. The game stays live.In the full version, the monsters refresh every 15 seconds, each kill reads its record again, and the red door asks Connect AI once more, live. Nothing in your apps is ever changed.
your question → Claude ⇄ Connect AI MCP server ⇄ Salesforce, Zendesk, Stripe, … → a Doom level: rooms, records, doors, a vault → you (or Claude) clear it

THIS WEB VERSION

This is a real level: Claude built it through the Connect AI MCP server from a demo CRM, help desk and billing account, and every monster is a record Claude read. The game runs entirely in your browser.

The side panel has three tabs. Live feed follows your game, with what Claude said about each record when it played this level. Leaderboard shows how Claude and other models did when they played it. How Claude built it shows every call Claude made to Connect AI, with the SQL it wrote.

There's no sound yet. Asking new questions, live reads and letting Claude play need the full version.
